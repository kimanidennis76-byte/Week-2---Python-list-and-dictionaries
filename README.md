# Week 2 - List and dictionaries

This repository contains lists and dictionaries covered in week 2

# Topics covered
Lists and how to access, slice, and loop through them
List methods, adding, removing and sorting
Dictionaries and key value data
Nested data and string method
Mini-project: Contact Book

# Learning goals
The goal of Week 2 was to move beyond individual variables and learn how 
to store, organize, access, modify, and process collections of data.

A particular focus was placed on lists, dictionaries, and combinations of the two to represent structured information.

Finally I built a contact book that stores names, phone numbers, and emails and runs as a fully interactive terminal application
